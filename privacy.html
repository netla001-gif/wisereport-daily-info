WiseReport Daily · 시행일 2026년 9월 28일

처리하는 정보와 목적

프로그램은 사용자가 허용한 WiseReport 리포트의 목록 정보와 PDF를 처리합니다. Google OAuth 인증 정보, 지정된 Drive 폴더 및 생성한 파일의 ID·이름·공유 상태·웹 링크는 본인 Drive에 자료를 저장하고 중복 업로드를 방지하는 데 사용합니다. Telegram 봇 토큰과 채팅 ID는 본인에게 요약을 보내는 데 사용합니다.

저장과 전송

인증 토큰, 로그인 세션, SQLite 데이터베이스와 다운로드 파일은 사용자의 컴퓨터에 저장됩니다. PDF는 사용자가 지정한 Google Drive 폴더로 전송되고, 기업·산업별 통계와 리포트 제목·증권사·페이지 수·Drive 링크는 사용자가 지정한 Telegram 채팅으로 전송됩니다. Drive PDF의 공유 권한은 공개로 바꾸지 않습니다. 별도의 운영자 수집 서버로 인증 정보나 파일을 전송하지 않습니다.

이용 제한

Google 사용자 데이터는 이 프로그램의 저장·정리·알림 기능을 제공하는 데만 사용합니다. 광고, 데이터 판매 또는 AI 모델 학습에 사용하지 않습니다. Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.

보관, 삭제와 접근 철회

로컬 데이터는 사용자가 삭제할 때까지 보관됩니다. 자동 실행을 해제하고 프로젝트의 인증 파일·데이터베이스·다운로드 파일을 삭제할 수 있습니다. Google 계정의 연결된 앱 설정에서 접근 권한을 철회할 수 있습니다. Drive에 저장된 파일 및 Telegram 메시지는 각 서비스에서 별도로 삭제해야 합니다. 봇 토큰은 BotFather에서 철회할 수 있습니다.

안내 웹사이트

이 안내 페이지에는 로그인, 입력 양식, 광고, 분석 스크립트가 없습니다. 웹 호스팅 제공자는 페이지 제공을 위한 접속 정보를 자체 정책에 따라 처리할 수 있습니다.
